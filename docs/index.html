How to open The Hike Insole Book — no deployment

Yes. This is already a website that lives on this Mac. You do not upload it, you do not need a domain, and you do not need the internet after the files are on disk.

1. What you have

The book is a folder of static files: one HTML page, JavaScript, 3D models, and a short intro video. A browser draws the site. A tiny Python script only exists so the browser is allowed to load those local 3D files.

Nothing is “in the cloud.” Opening the book does not publish it. Nobody else can see it unless they are on this computer (or you copy the folder to theirs).

2. Why there is a local address

If you double-click index.html as a file, Chrome blocks the 3D models (module imports). So we start a local server that only listens on this machine:

http://localhost:8471/index.html

localhost means “this Mac.” It is not a public website. Close the terminal (or quit the server) and the address dies. The files stay.

3. Start it — pick one way

Way A — double-click (easiest)

  1. Open Finder → Downloads → hike-insole-book
  2. Double-click Start Book.command
  3. If macOS asks, allow it. The book opens in your browser.

That command starts Python on port 8471 only if nothing is already using it, then opens the page.

Way B — Terminal (the commands, nothing overwritten)

cd /Users/surya/Downloads/hike-insole-book
python3 tools/serve.py

Leave that window open. In a second tab, or after it prints the URL:

open http://localhost:8471/index.html

To stop the server: click that Terminal window and press Ctrl + C.

If you see Address already in use, the book is already running. Just open the URL. Do not start a second copy.

Way C — these docs only (no server required)

These three documentation pages are plain HTML. You can open them from Finder:

  1. Go to hike-insole-book/docs/
  2. Double-click index.html, build.html, or app.html

Or, with the book server already running:

http://localhost:8471/docs/index.html

4. What you see when it starts

  1. Logo hold — the hike wordmark, about two seconds.
  2. Intro video once — does not loop. Skip is on the bottom right. If the browser blocks sound, tap Play.
  3. The course screen — one screen, no page scroll. Chapters and lessons are in the left sidebar (click a chapter to open its lessons); the 3D stage and lesson text fill the rest. Library at the bottom of the sidebar swaps the stage for the device grid.

The intro plays once per browser tab session. To see it again, open a new tab or in the browser console run:

sessionStorage.removeItem('hikeIntro')

then refresh.

6. What you do not need

  • No GitHub, no Pull Request, no deploy, no Surge, no Netlify.
  • No login. No API key to view the book.
  • No rebuild just to open it. Models are already in models/.
