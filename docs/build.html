How the 3D book is built

The pages you click are HTML. The insoles you rotate are real production meshes, converted once on this Mac into small web files. You do not rebuild to open the book — only when a new STL must replace an old one.

1. Two kinds of 3D, on purpose

KindWhat you seeHow it is made
Single insole One black shell. Amber = raise, cyan = well — teaching paint on the mesh. tools/build_models.py reads a taika STL and writes models/CPO-…_LEFT.glb.
Pair (insole + part) Black production insole plus a separate colored part that lifts, presses, flips, or drapes. tools/build_pairs.py writes two GLBs: the insole and …_addon.glb.

Color on a pair is a teaching highlight. After a lift or press settles, the colored part fades so the insole looks the way it ships — one black device. Top covers and cork wedges stay, because they are the finished surface.

2. Where the raw STLs live

The build scripts do not invent geometry. They read folders next to the book:

FolderContents
/Users/surya/Downloads/po-insole-stls/Whole-insole taika STLs used by build_models.py.
/Users/surya/Downloads/pair-insole-stls/Matching insoles for animated pairs.
/Users/surya/Downloads/insole-addon-stls/Production “extra” STLs — met pad, offload plug, toe crest, and so on.

Those extras are often print pucks: the real shape sits on a tall support. The pair script subtracts the insole height from the puck crown and rebuilds a thin part that sits on the insole. If a file also has a floating print plate (the 1900049 toe crest did), the script keeps only the low band.

3. Step-by-step: a single insole (highlights)

  1. Put the STL in po-insole-stls and list it in tools/insole-types.csv (type, additions — no PO on the student’s screen).
  2. Run, from the book folder, using the project Python that already has trimesh:
cd /Users/surya/Downloads/hike-insole-book
"/Users/surya/Downloads/Ops Agent/.venv/bin/python" tools/build_models.py
  1. The script simplifies the mesh (about 28k faces), centers it, and paints vertices: black shell, amber where a raise is prescribed and the surface actually rises, cyan where a well is prescribed and the surface actually drops.
  2. It writes models/{PO}_{SIDE}.glb and merges a row into catalog.json.
Do not run this “to refresh the book.” It only replaces GLBs for POs in that CSV. The pair entries and cover lineup are merged in, not wiped, as long as the script’s merge path is the one you are using.

4. Step-by-step: an animated pair (pad, bar, offload, cover, wedge)

  1. In tools/build_pairs.py, a PAIRS row names the insole file, the extra STL, the color (amber lift vs cyan press), and a thickness cap.
  2. The script samples both meshes onto a 1 mm grid, computes thickness, builds a solid for the part, and exports two GLBs that share one coordinate frame — that is why the part can lift off and sit back down.
  3. Motion is stored on the catalog row: lift (pads, bars, crests), press (soft fills), flip (cork wedge), drape (top cover, heel-first).
cd /Users/surya/Downloads/hike-insole-book
"/Users/surya/Downloads/Ops Agent/.venv/bin/python" tools/build_pairs.py

A full run also rebuilds every T-code cover. For one pair only, the same functions can be called for a single id (that is how the 1900049 toe crest was swapped).

Top covers (T1–T14)

Covers are not photos on the insole. Each T-code is a layered GLB at true millimeters, colors sampled from the lab sheets into assets/topcovers/palette.json. The student picks a chip; the old sheet lifts and the new one drapes. Training mode draws leader lines to each layer with the real mm number.

Cork wedges

The wedge is the real blank STL, shortened heel-to-arch, high edge on the prescribed border, then trimmed to the insole’s bottom outline. Flip animation: device rolls over, part seats, device rolls back. Color is shell black — it is not a teaching tint.

5. The catalog is the index

catalog.json is a list of devices. Each row has a po (often a lesson id like PAIR-MET-PAD, never shown as a customer PO), a motion, and models.LEFT / RIGHT with file and optional addon.

Lessons in content.js point at that po. If the catalog row is missing, the stage is empty. If the GLB path is wrong, the browser console shows a load error.

6. When you actually rebuild

  • New or better STL (example: order 1900049 toe crest) — replace the file in the STL folder, point build_pairs.py at it, rebuild that pair, refresh the browser.
  • New lesson text only — edit content.js. No Python. Refresh.
  • Just open the book — do not run any build. Use Page 1.

Python packages (trimesh, numpy, scipy, shapely) live in Ops Agent/.venv. The book server itself only needs the Mac’s python3.
